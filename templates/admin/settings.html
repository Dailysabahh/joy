How to swap phone numbers for a new customer

  1. Add the new customer's phone number to your WhatsApp Business API app in Meta Business Manager (or use a fresh Meta app).
  2. Get the new Phone Number ID from Meta Business → WhatsApp → API Setup.
  3. SSH into the server: ssh -i ~/Downloads/joy.pem ubuntu@13.60.238.119
  4. Edit the env file: sudo nano /opt/joy/.env
  5. Update WHATSAPP_PHONE_NUMBER_ID with the new value.
  6. Update WHATSAPP_TOKEN if the new number uses a different access token.
  7. Restart Joy: sudo systemctl restart joy
  8. Update the webhook URL in Meta if you used a different app.
